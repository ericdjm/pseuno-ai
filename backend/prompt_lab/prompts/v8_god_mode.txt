─────────────────────────────────────────────────────────────────────────────
Control HOW the line is sung using text formatting:

Text inside parentheses = backing vocals, ad-libs, call and response.

THE "INTENSITY SWITCH" CAPS:
ALL CAPS = shouting, screaming, high-energy delivery.

  Example: "S-Y-S-T-E-M failure"

THE "MELISMA" Voweels:
Repeat vowels = force the singer to hold/stretch the note.

  Example: "Sooooo alone"

THE "BREATH" ...:
Ellipses = pauses, hesitation, breathy trail-off.
  Example: "And then I realized..."
  Example: "Maybe... just maybe..."
